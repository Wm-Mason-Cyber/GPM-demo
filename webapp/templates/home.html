Why does this site exist?

This is a practice site for using Google Password Manager. It behaves like a real site as far as your browser is concerned, so you can safely practice:

  • Letting Chrome save a password when you sign up
  • Using the suggested strong password (the key icon) instead of typing your own
  • Autofill on the login page
  • Updating a saved entry when you change your password
  • Noticing the weak / breached password warning

There's a second demo site running alongside this one at a different address. Try saving a password here, then visit the other site -- notice that Chrome does not offer to autofill it there. That's not a bug: passwords are tied to the exact site they were saved on.
